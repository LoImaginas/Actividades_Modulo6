# Actividad Módulo 6 - Restaurantcito

Proyecto realizado como actividad práctica del módulo 6, recreando una página de restaurante con Vue 3 + Vite y estilos con Bootstrap.

## Tecnologías usadas

- Vue 3
- Vite
- Bootstrap 5
- CSS

## Objetivo

Recrear la maqueta entregada, respetando su estructura visual, secciones principales y estilo general.

## Vista del proyecto

Incluye:

- Navbar con logo y menú
- Sección principal con cards de platos
- Sección de medios de pago
- Footer de contacto
